# Wood-Chuck-Storefront
Online storefront for Chuck's woodworking hobby!

A full-stack storefront for a custom woodworking business. Customers can browse products, submit project requests, and track their orders.

## Tech Stack

- **Frontend:** React, Vite, React Router
- **Backend:** Node.js, Express
- **Database:** MySQL (planned)
- **Hosting:** AWS (planned)

## Getting Started

Requires [Node.js](https://nodejs.org) (LTS).

```bash
# Backend
cd server
npm install
npm run dev

# Frontend (in a second terminal)
cd client
npm install
npm run dev
```

The API runs on `http://localhost:3000` and the app on `http://localhost:5173`.
